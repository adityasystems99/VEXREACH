## Reporting a Vulnerability

The VEXReach team takes security vulnerabilities seriously.

If you discover a security vulnerability in VEXReach (such as an execution escape, AST parser bypass, untrusted input vulnerability, or prompt injection vulnerability in advisory processing):

1. **Do NOT open a public GitHub issue.**
2. Report the vulnerability privately by emailing: `security@vexreach.org` (or via GitHub Private Vulnerability Reporting).
3. Include:
   - A description of the vulnerability.
   - Steps to reproduce the issue (proof-of-concept repository or test payload).
   - Potential impact of the issue.

We will acknowledge receipt within 48 hours and provide a timeline for triage and remediation.
