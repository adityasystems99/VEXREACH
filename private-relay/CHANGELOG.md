# Changelog — Private-Relay Protocol

All notable architectural, protocol, and implementation milestones are recorded chronologically here.

## `[0.1.0-day4]` — 2026-11-27 (Day 4 Independent Engineering Verification & Hardening)
- **Independent Audit & SSRF Fix (`D4-01`):** Expanded [crates/network/src/policy.rs](./crates/network/src/policy.rs) to block IPv4-compatible IPv6 (`::/96` via `to_ipv4()`), deprecated site-local (`fec0::/10`), discard (`0100::/64`), Teredo (`2001::/32`), benchmarking (`2001:2::/48`), SIIT (`::ffff:0:0:0/96`), 6to4 (`2002::/16`), and `%` IPv6 zone IDs, with regression tests in [crates/network/tests/network_tests.rs](./crates/network/tests/network_tests.rs).
- **Exit Replay Window & Unified Timeout (`D4-02`):** Replaced bulk `used_request_ids.clear()` with bounded FIFO eviction (`VecDeque<u32>`) and consolidated Exit DNS/connect/I/O under one `timeout(dest_timeout, ...)` deadline in [crates/relay/src/engine.rs](./crates/relay/src/engine.rs).
- **Verification & Offline Dependency Inventory:** Added [DAY4_VERIFICATION_REPORT.md](./DAY4_VERIFICATION_REPORT.md); verified `0` first-party `unsafe` matches, permissive `cargo tree` dependency licenses, live 5-process demo reproduction with `POST_PROCS=0` leak check, and `40/40` tests + `clippy -D warnings`.

## `[0.1.0-day3]` — 2026-11-27 (Day 3 CLIs, Multi-Process Demo, Link Rekeying & v0.1 Prototype Release)
- **Implemented Synchronized Noise Link Rekeying (`D-09`):** Added in-band encrypted `RekeyControl { epoch }` framing (`crates/protocol`), coordinated `LinkSession::seal_rekey_and_rotate` / `open_frame` via `snow::TransportState::rekey_outgoing` & `rekey_incoming` (`crates/crypto`), and automatic time/byte threshold triggers (`3600s` / `1 GiB` defaults) in `LinkWriter` / `LinkReader` (`crates/network`) with fail-closed session poisoning on any malformed, replayed, or interrupted frame.
- **Operational Hardening:** Added `StaticKeypair::from_slices` X25519 mathematical keypair consistency verification (`SEC-203`), `RelayRuntime` `max_concurrent_connections` accept semaphore (`default = 256`, `SEC-202`) + `RelayHandle::active_connection_count()`, Exit `timeout(dest_timeout, policy.resolve_and_validate(...))` (`SEC-201`), expanded IPv4/IPv6 SSRF ranges (`0.0.0.0/8`, NAT64 `64:ff9b::/96`, doc/benchmark blocks, `SEC-204`), `RelayConfig` topology/role/loop checks, and `ClientConfigFile` TOML schema + validation.
- **Added `crates/cli` (`private-relay-cli`):** Standalone executables `relay-entry`, `relay-middle`, `relay-exit`, `relay-client`, `demo-dest`, and `relay-keygen` supporting `--config`, `--check-only`, `--url` / `--target`, sanitized status/byte/timing reports (body suppressed unless `--print-body`), and Ctrl+C graceful shutdown.
- **Added `demo/` Reproducible Multi-Process Harness:** Config templates ([demo/configs/](./demo/configs/)), [demo/generate-identities.ps1](./demo/generate-identities.ps1), [demo/start-demo.ps1](./demo/start-demo.ps1) (launching relays with `--log-level debug`), [demo/run-demo.ps1](./demo/run-demo.ps1) (including multi-process log verification), [demo/stop-demo.ps1](./demo/stop-demo.ps1), and [demo/README.md](./demo/README.md), keeping generated secrets in gitignored `demo/generated/`.
- **Completed Security Review & Tests:** Upgraded [SECURITY_REVIEW.md](./SECURITY_REVIEW.md) (`Critical` / `High` / `Medium` / `Low` / `Informational` findings), enhanced `cli_tests.rs` (5-process distinct-PID & zero-leak log verification), added `exit_enforces_destination_timeout_and_cleans_up_circuit`, and verified `cargo test --offline --workspace` (`40/40` passing), `clippy -D warnings`, `cargo fmt --check`, and live Windows PowerShell multi-process demo execution (`10/10` scenarios + relay log proofs). Docker, Kubernetes, Prometheus, and LLM integrations remain deferred beyond `v0.1`.

## `[0.1.0-day2]` — 2026-11-26 (Day 2 Cryptography, Transport, Relay Engine & 3-Hop Client)
- **Added `crates/crypto` (`private-relay-crypto`):** `StaticKeypair` (`ZeroizeOnDrop`), `LinkInitiator`/`LinkResponder`/`LinkSession` (`Noise_IK` + exact `600B` fixed frames via `snow v0.9.6`), `HopHandshakeInitiator`/`HopHandshakeResponder`/`HopCipherPair`/`ClientCircuitCrypto` (`Noise_NK` + transcript-salted `HKDF-SHA256` per `D-08` + strict FIFO `ChaCha20-Poly1305` `15B` AAD per `D-07`).
- **Added `crates/network` (`private-relay-network`):** `RelayRole`, `PeerDescriptor`, TOML-serializable `RelayConfig`, DNS-once SSRF-blocking `DestinationPolicy`, and async `LinkReader`/`LinkWriter` handling partial TCP reads/writes (`recv_cell_with_timeouts`) and `Noise_IK` links.
- **Added `crates/relay` (`private-relay-relay`):** Single parameterized `RelayServer`/`RelayHandle` supporting `Entry`, `Middle`, and `Exit` roles, multiplexed outbound `PeerLink` pool, cancellation-safe hop extension, global & per-IP capacity limits, bounded `mpsc` backpressure, role/allowlist checks, Exit request reassembly & bounded response execution, and PII-free structured logging.
- **Added `crates/client` (`private-relay-client`):** `RelayClient::connect_three_hop` (fresh per-session ephemeral keypair + 3 telescopic hops) and `ClientCircuit::send_request`/`close`.
- **Reconciled Documentation:** Recorded `D-08` in [DECISIONS.md](./DECISIONS.md), updated [SECURITY_DESIGN.md](./SECURITY_DESIGN.md), [KNOWN_ISSUES.md](./KNOWN_ISSUES.md), [PROJECT_STATUS.md](./PROJECT_STATUS.md), [ROADMAP.md](./ROADMAP.md), and [TEST_RESULTS.md](./TEST_RESULTS.md).
- **Verified Checks:** `cargo fmt --all -- --check`, `cargo clippy --offline --workspace --all-targets -- -D warnings`, and `cargo test --offline --workspace` (`29 passed; 0 failed; 0 ignored`).

## `[0.1.0-day1]` — 2026-11-26 (Day 1 Protocol Core & Architecture Freeze)
- **Approved & Recorded Decisions:**
  - `D-01`: Approved Choice A — Bounded Request/Response Forwarding (`<= 64 KiB` request & response, `<= 140` chunks per logical message, `RequestId` association) over bidirectional relay-link TCP connections.
  - `D-02`: Reconciled wire arithmetic so complete on-wire outer Noise frame = `600` bytes exact (`2B outer_len == 598` + `582B` padded outer plaintext + `16B` Noise MAC); max inner `Cell` = `580B` (`9B` header + `<= 571B` body); `InnerPayload` = `<= 496B` (`9B` header + `<= 487B` fragment, fitting `64 KiB + 257B` target header in `136 <= 140` chunks).
  - `D-07`: Corrected end-to-end per-hop AEAD AAD to omit link-local `CircuitId`, binding `b"PRv1" || version || direction || hop_index || seq` (`15B`), paired with ephemeral per-circuit `Noise_NK` keys and link-layer `Noise_IK` authentication.
- **Updated Docs:** `DECISIONS.md`, `PROTOCOL_SPEC.md`, `SECURITY_DESIGN.md`, `MVP_SCOPE.md`, `THREAT_MODEL.md`, `ROADMAP.md`, `KNOWN_ISSUES.md`, `PROJECT_STATUS.md`, `TEST_RESULTS.md`, `README.md`.
- **Implemented Workspace & Protocol Crate:** Created `private-relay/Cargo.toml` and `private-relay-protocol` (`constants`, `error`, `circuit`, `request`, `cell`, `frame`, `message`, `lib`, `tests/protocol_tests.rs` with zero external crate dependencies).
