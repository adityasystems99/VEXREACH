## Capability Implementation Breakdown

- **Implemented & Verified (`v0.1` Days 1–10):**
  - `private-relay-protocol` (`10/10` tests): bounded `600B` link frames (`D-02`), link rekey control framing (`D-09`), `9B` cells, `<= 64 KiB` chunking/reassembly (`D-01`), `15B` hop AAD (`D-07`).
  - `private-relay-crypto` (`6/6` tests): `Noise_IK` + synchronized link rekeying (`snow::TransportState`), inbound nonce saturation guard (`SEC-701`), `Noise_NK` hops + `D-08` exporter, `ChaCha20-Poly1305` FIFO replay protection, `StaticKeypair` consistency validation & `ZeroizeOnDrop`.
  - `private-relay-network` (`7/7` tests): TOML `RelayConfig` + `ClientConfigFile` validation, secret redaction & `Zeroize` (`SEC-704`), hardened `private_key_file` (`SEC-703`), hardened IPv4/IPv6 `DestinationPolicy` (`SEC-708`), cancellation-poisoned `LinkReader`/`LinkWriter` (`SEC-702`), zero-PII `RelayMetrics` (`crates/network/src/metrics.rs`).
  - `private-relay-relay` (`10/10` tests): parameterized `Entry`/`Middle`/`Exit`, `max_concurrent_connections` + `max_circuits_per_peer_ip` DoS limits, outbound trunk backpressure isolation (`SEC-705`), graceful shutdown draining (`SEC-706` + shutdown-race fix), live Prometheus `/metrics` & `/healthz` HTTP endpoint (`metrics_tests.rs`).
  - `private-relay-client` (`16/16` tests = `11` E2E integration + `5` resilience/concurrency/metrics E2E): `64 KiB`, SSRF, timeout cleanup (`SEC-707`), `1/5/10/25` concurrency ramp, relay restart recovery, mid-flight `SIGTERM` drain, & live 3-hop Prometheus scrape verification.
  - `private-relay-cli` (`5/5` tests), [Dockerfile](./Dockerfile), [docker-compose.yml](./docker-compose.yml), [k8s/](./k8s/README.md), & [demo/](./demo/README.md): standalone binaries (`--metrics-addr`, `--probe`, `--probe-noise`, `--probe-http`), `12/12` Docker Compose E2E, live `kind` (`v1.32.2`) + Calico (`v3.29.1`) deployment (`6/6` Deployments `1/1`, `2/2` Jobs Complete, `12/12` in-cluster traffic, `15/15` CNI policies, `3/3` Prometheus scrape targets `up`, 10-panel Grafana dashboard verified).
- **Partially Implemented / Platform-Scoped:** Multi-node WAN deployment, horizontal multi-replica relay scaling (`KI-10`), and long multi-hour soak runs have not been executed (`v0.1` uses single-replica Relays on local `kind` and Docker Compose).
